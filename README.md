# FinGuard

Telegram-бот для контроля личных расходов и расчета дневного лимита.

## Что делает

- ведет баланс и историю трат;
- считает дневной лимит;
- хранит регулярные подписки и счета;
- строит отчет по категориям расходов;
- отправляет утренний статус по лимиту.

## Стек

- Python 3.10+
- aiogram
- aiosqlite
- matplotlib

## Быстрый старт

1. Создай и активируй виртуальное окружение.
2. Установи зависимости:

```bash
pip install -r requirements.txt
```

3. Создай `.env` по примеру `.env.example` и укажи токен:

```env
BOT_TOKEN=your_telegram_bot_token_here
```

4. Запусти бота:

```bash
python main.py
```

## Файлы проекта

- `main.py` - запуск бота и планировщика;
- `handlers.py` - команды и сценарии бота;
- `logic.py` - расчетная логика;
- `database.py` - работа с SQLite;
- `visuals.py` - графики отчетов.
